# 동상이몽 그림 퀴즈

미술 수업용 게임입니다. 화면에 나온 동음이의어(배, 밤, 눈, 차 …)를 보고 선생님과 멘티가 상의 없이 각자 그림을 그린 뒤, 같은 뜻을 그렸으면 성공입니다.

- 표지 → 게임 규칙·준비물 → 동음이의어란? → 본 게임 안내 → 연습 게임(배) → 본 게임 20문제(쉬움 7 → 중간 7 → 어려움 6, 초등학생이 아는 한글 낱말) → 결과
- 라운드마다 타이머(기본 1분 30초), 그림 공개(뜻 카드), 성공·실패 점수
- 7점 이상이면 오늘의 퀘스트 complete
- 체험 모드: `?trial=1` (2번 문제까지)
- 단일 파일 정적 페이지 (`index.html`), 별도 빌드 없음
